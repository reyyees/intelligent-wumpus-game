# Intelligent Wumpus Agent

This project consists of an automatic Wumpus game agent developed in Python.

The agent autonomously explores the environment searching for the gold while avoiding the Wumpus and moving holes.

## Features

- Autonomous agent behavior
- Grid-based environment
- Dynamic hazards
- Intelligent decision-making
- Visual representation using images

## Technologies

- Python
- Jupyter Notebook
- AI / Search logic
